# Arthiq - India's AI Financial Intelligence Platform

Arthiq is a comprehensive, AI-powered financial intelligence platform designed securely for Indian retail investors. 
We combine live NSE/BSE market data with cutting-edge AI to explain not just what the markets are doing, but WHY they are doing it.

## Features
- **Live NSE/BSE Market Data**
- **AI-Powered Insights** using OpenAI's engines
- **Price Forecasting (2-4 week outlook)**
- **Forex and Macroeconomic Tracking**
- **Sleek, Dynamic User Interface**

## Setup
1. Clone the repository
2. Provide your `.env` keys for Supabase and the respective backend endpoints
3. Start the backend with `uvicorn app.main:app --reload`
4. Start the frontend with `npm run dev`
